# Baseline Reproduction Guide

This guide explains how to reproduce the baseline method from the paper exactly.

## Quick Start

1. **Identify the baseline parameters from the paper:**
   - SVM cost parameter (C)
   - Number of features used
   - Kernel type (usually "linear")
   - Whether SMOTE was used
   - Classification vs Regression mode
   - Cross-validation method (if any)

2. **Edit `ReproduceBaseline.R`:**
   - Open the file and modify the configuration section at the top
   - Set all parameters according to the paper

3. **Run the script:**
   ```r
   source('ReproduceBaseline.R')
   ```

## Configuration Parameters

### Data Balancing
```r
balancing = "";  # No SMOTE (imbalanced baseline)
# OR
balancing = "_SMOTED";  # With SMOTE
```

### Feature Scheme
```r
fScheme = "_comb";  # Combined features (n-grams, nGDip, PSF)
# OR
fScheme = "_comb_pseAAC";  # Combined features with pseAAC
```

### Classification Mode
```r
DoRegression = FALSE;  # Classification mode (typical baseline)
# OR
DoRegression = TRUE;  # Regression mode
```

### SVM Parameters
```r
svmCostList = c(1);  # Single C value (check paper)
# OR
svmCostList = c(0.3, 1, 3, 10, 30, 100);  # Multiple values for grid search

svmKernel = "linear";  # Linear kernel (typical baseline)
```

### Feature Selection
```r
featureCountList = c(2800);  # Specific number of features
# OR
featureCountList = c(Inf);  # All features (no selection)
```

### Evaluation Method
```r
useCV = FALSE;  # Independent test set (typical baseline)
# OR
useCV = TRUE;  # Cross-validation
nFolds = 10;  # 10-fold CV
# OR
nFolds = -1;  # Jackknife (leave-one-out)
```

## Required Files

Before running the script, ensure these files exist:

1. **Training data:** `trainingset.csv` (with columns: Sequence, Class)
2. **Test data:** `testingset.csv` (with columns: Sequence, Class)
3. **Feature files:** Generated by running featurization first
   - `featurized_<fScheme><balancing>.rds`
   - `testFeaturized_<fScheme>.rds`
4. **Feature ranking:** `rankedFeatures.rds` (will be generated if missing)

## Generating Required Feature Files

If feature files don't exist, you need to run featurization first. You can use the existing scripts or create features manually:

```r
source('featurization.R');

nTrainingSet = read.csv('trainingset.csv')
nTestSet = read.csv('testingset.csv')

amins = c("A", "C", "D", "E", "F", "G", "H", "I", "K", "L", "M", "N", "P", "Q", "R", "S", "T", "V", "W", "Y");

alldata = rbind(nTrainingSet, nTestSet)
featurizeddata = featurization(
  alldata$Sequence, 
  alldata$Class, 
  amins, 
  nGramOrder = 3,    # Check paper for exact values
  nGDipOrder = 15,   # Check paper for exact values
  psfOrder = 3       # Check paper for exact values
);

nTrain = length(nTrainingSet[,1])
features = featurizeddata[1:nTrain,]
testFeatures = featurizeddata[(nTrain+1):(nTrain+length(nTestSet[,1])),]

saveRDS(features, "featurized_comb.rds")
saveRDS(testFeatures, "testFeaturized_comb.rds")
```

## Output

The script generates:
- **CSV file:** `baseline_out_<fScheme><balancing>.csv` with detailed results
- **Console output:** Summary of best results

## Troubleshooting

### Error: Feature file not found
- Run featurization first to generate the required `.rds` files
- Check that `fScheme` and `balancing` match the file names

### Error: Feature ranking file not found
- The script will generate it automatically using Random Forest
- Or ensure `rankedFeatures.rds` exists in the current directory

### Results don't match paper
- Verify all parameters match the paper exactly
- Check random seed (set in script)
- Ensure data preprocessing matches (shuffling, class encoding)
- Verify feature extraction parameters (nGramOrder, nGDipOrder, psfOrder)

## Notes

- The script uses `set.seed(10)` for reproducibility. Change this if the paper specifies a different seed.
- Random shuffling is commented out by default. Uncomment if the paper mentions shuffling.
- For regression mode, the threshold is optimized based on accuracy unless the paper specifies a fixed threshold.
